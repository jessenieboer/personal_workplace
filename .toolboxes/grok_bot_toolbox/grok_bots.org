#+begin_src text :json skills
  ## Required Inputs
  The task, and the bot whose job covers it.

  ## Handoff report
  Every report back on a handed-off task carries:
  - Completed: what was done.
  - Evidence: the output path, commit, link, or check run that shows it.
  - Unresolved: what is still open, or "none".
  - Next: who owns the next step (the sender, the user, or a named bot), or "none".

  ## Workflow
  Sending:
  1. Check the receiving bot's job covers the task. Not covered -> tell the user instead of sending.
  2. Send one message with:
     - Result: what done looks like, and that the receiver owns it.
     - Context: why, and what the user asked, quoted when it matters.
     - Inputs: exact names, paths, IDs, and links. No "the file" or "that project".
     - Constraints: the user's standing rules that apply, such as not pushing, checking a drive is mounted, or days off.
     - Report: who gets the handoff report (you or the user), and anything it must include beyond the four fields.
  3. Stop working on the task. Leave the receiver's work to the receiver unless the user asks you to check it.
  4. Tell the user who has it.

  Receiving:
  1. Check the task is in your job. Not in it -> say so to the sender, and name the right bot if you know it.
  2. Check you have every input. Missing one -> ask the sender once, listing everything missing.
  3. Do the work, then send the handoff report to whoever the handoff names. Blocked partway -> send it with what is done so far, and the blocker under Unresolved.
#+end_src

The merge script lives only here, inline in the command, so no script file is written. Tested copy: /tmp/mdm/merge_md.awk.
#+begin_src text :json skills
  ## Workflow
  1. Find the project's root directory.
     - Path given and it exists -> use it.
     - Name only -> use its root from the project list in shared memory.
     - Not listed, or path not found -> ask. Don't guess.
  2. Merge every AGENTS.md under the root into /tmp/agents-merged.md. Files go shallowest first. Sections with the same heading path are combined, and each chunk is marked with its source file. "skill-librarian" sections are dropped; they list skill sources for the Skill Librarian, not project rules. Run this one command as written, with `<root>` filled in, on the computer the project lives on:
     ````sh
     cd <root> && find . -name AGENTS.md -not -path '*/.git/*' -not -path '*/node_modules/*' \
       | awk -F/ '{print NF "\t" $0}' | sort -n | cut -f2- | tr '\n' '\0' \
       | xargs -0 -r awk '
     # Merge Markdown files. Sections with the same heading path are combined:
     # bodies are appended in file order, each chunk marked with its source file.
     # Headings inside ``` or ~~~ fences are ignored. A "skill-librarian" heading
     # and its text, up to the next heading, are dropped.
     FNR == 1 { cur = 0; depth = 0; path[0] = 0; fence = 0; skip = 0 }
     /^(```|~~~)/ { fence = !fence }
     !fence && /^#+ / {
       match($0, /^#+/); l = RLENGTH
       if (l <= 6) {
         t = tolower($0); sub(/^#+[ \t]+/, "", t); sub(/[ \t#]+$/, "", t); gsub(/[ \t]+/, "-", t)
         skip = (t == "skill-librarian"); if (skip) next
         while (depth > 0 && lvl[path[depth]] >= l) depth--
         k = path[depth] SUBSEP $0
         if (!(k in id)) { id[k] = ++n; title[n] = $0; lvl[n] = l; kids[path[depth]] = kids[path[depth]] " " n }
         path[++depth] = id[k]; cur = id[k]; next
       }
     }
     skip { next }
     {
       if (src[cur] != FILENAME) {
         if ($0 ~ /^[ \t]*$/) next
         src[cur] = FILENAME; sub(/\n+$/, "\n", body[cur]); body[cur] = body[cur] (body[cur] == "" ? "" : "\n") "<!-- from " FILENAME " -->\n"
       }
       body[cur] = body[cur] $0 "\n"
     }
     function emit(i,   a, m, j, b) {
       if (i) print title[i] "\n"
       b = body[i]; sub(/\n+$/, "", b)
       if (b != "") print b "\n"
       m = split(kids[i], a, " ")
       for (j = 1; j <= m; j++) emit(a[j])
     }
     END { emit(0) }
     ' > /tmp/agents-merged.md
     ````
     - Output empty -> tell the user no AGENTS.md was found, and stop.
  3. Read /tmp/agents-merged.md into this conversation in full. Keep it out of memory. Done when all of it has been read.
  4. Quick-check what you read for contradictions: two chunks giving opposite rules, or a rule that conflicts with this bot's description or memory. A deeper file narrowing a shallower one is not a contradiction.
     - Any found -> list each one with both source paths (from the `<!-- from ... -->` markers) and the conflicting lines, and ask the user which wins. Don't guess.
  5. Confirm the project is grokked: name, root directory, the AGENTS.md files read, and any contradictions still open.
