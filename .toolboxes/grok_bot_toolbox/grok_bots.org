***** Journeyman template
#+begin_src text :json skills
  ## Journeyman template
    Use this copy. Don't look up a file.

    Name: `<project> Journeyman`

    Description (use verbatim):
      Job description: Given a project, load project-specific facts, then assist in project-specific work as you are directed by the user.

      If user instructions conflict with project-specific facts, the user wins.

      Be terse.

    If `grok-project` is not in the shared library, install it with this exact description and body. Overwrite an existing copy.

    Description: For Journeyman only. Use when the user names a project or directory to work in, or when starting work in a project not yet grokked in this conversation.

    Body:
      ## Required Inputs
        A project name, or a path to its root directory, or both.

      ## Workflow
        1. Find the project's root directory.
          - Path given and it exists -> use it.
          - Name only, or path not found -> ask. Don't guess.
        2. Search the project recursively for AGENTS.md files.
        3. Read each file into this conversation once. Don't copy them into memory.
          - None found -> tell the user, and stop.
          - Many found -> read the root one first, then the rest, and list them.
        4. Confirm the project is grokked: name, root directory, and which AGENTS.md files were read.
#+end_src
***** Exact workflow
#+begin_src text :json skills
  ## Workflow
    1. If the project name or its directory is missing, ask. If you already have the directory for that name, use it. Don't guess a path.
    2. If a Journeyman for this project already exists, stop and tell the user. Don't create a second one unless they say to.
    3. Create a new bot named `<project> Journeyman` using the description in this skill.
    4. Make sure `grok-project` is in the shared skill library. If it isn't, install it from the copy in this skill. Overwrite an existing copy.
    5. Message the new bot to update its profile:
       avatar_shape: capsule
       avatar_color: gray
    6. Message the new bot with the project name and root directory, telling it to run grok-project. Don't wait for its reply in this turn.
    7. Confirm to the user: the new bot's name, that it was asked to grok the project, and the project directory.
#+end_src

#+begin_src text :json skills
  ## Skill Librarian template
    Use this copy. Don't look up a file.

    Name: `Skill Librarian`

    Description (use verbatim):
      Job Description: Install skills in Grok Bot's skill library when named by the user or mentioned in a project's AGENTS.md.

    If `procure-skill` is not in the shared library, install it with this exact description and body. Don't overwrite an existing copy.

    Description: For Skill Librarian only. Use when the user names a skill to install, or when an AGENTS.md names a skill that is not already in the library.

    Body:
      ## Inputs
        A skill name, plus a URL or path to its directory when you have one.

      ## Workflow
        1. Find the skill directory (the folder that contains SKILL.md).
          - already have a URL or path -> use it
          - otherwise -> ask; don't guess a source
        2. If a skill with the same name is already in the library, stop and tell the user. Don't overwrite it unless they say to.
        3. Read SKILL.md. Save it to the shared skill library with its name, its "use when" description, and its body. Leave relative links as they are.
        4. Copy every companion file and subdirectory from the source folder into the saved skill's folder (references/, scripts/, and anything else SKILL.md points to). Skip files that are clearly for another product, such as an OpenAI Codex config.
        5. Confirm to the user: the skill name, that it is in the shared library, and which companion files were copied. Don't run the skill.
#+end_src

    3. Make sure `procure-skill` is in the shared skill library. If it isn't, install it from the copy in this skill. Don't overwrite an existing copy.
    4. Message the new bot to update its profile:
       avatar_shape: square
       avatar_color: brown
    5. Confirm to the user: the new bot's name, and that `procure-skill` is in the shared library.

# Tangling runs write-bots: one <name-slug>.json per top-level heading, beside this file.
# The tangle block below itself tangles nowhere; its :tangle header does the writing.
#+name: write-bots
#+begin_src emacs-lisp
(require 'json)
(require 'seq)
(require 'cl-lib)
(require 'subr-x)
(let* ((dir (file-name-directory (buffer-file-name)))
       (written nil)
       (avatar-shapes '("blob" "pebble" "bean" "egg" "squircle" "tablet"
                        "capsule" "cylinder" "hex" "gem" "crystal" "wedge"
                        "shield" "dome" "arch" "cloud" "teardrop" "leaf"
                        "square" "sparkle" "clover" "flower" "heart"
                        "house" "star"))
       (avatar-colors '("black" "brown" "red" "orange" "yellow" "green"
                        "cyan" "blue" "violet" "magenta" "gray"))
       (heading-at-point
        (lambda ()
          (substring-no-properties (org-get-heading t t t t))))
       (in-noexport-p
        (lambda ()
          (save-excursion
            (org-back-to-heading t)
            (catch 'found
              (while t
                (when (member "noexport" (org-get-tags nil t))
                  (throw 'found t))
                (unless (org-up-heading-safe)
                  (throw 'found nil)))))))
       (section-instance-field
        (lambda (section)
          (let* ((path (mapcar (lambda (h)
                                 (substring-no-properties (or h "")))
                               (append (org-get-outline-path)
                                       (list (funcall heading-at-point)))))
                 (idx (cl-position section path :test #'cl-equalp)))
            (when (and idx (nth (1+ idx) path) (nth (+ 2 idx) path))
              (list (nth (1+ idx) path) (nth (+ 2 idx) path))))))
       (push-field
        (lambda (cell key text)
          (let ((existing (assoc key (cdr cell))))
            (if existing
                (setcdr existing (concat (cdr existing) "\n\n" text))
              (setcdr cell (append (cdr cell) (list (cons key text))))))))
       (alist-keep
        (lambda (fields keys)
          (let (out)
            (dolist (k keys)
              (let ((v (cdr (assoc k fields))))
                (when (and v (not (string-empty-p (string-trim v))))
                  (push (cons (intern k) (string-trim v)) out))))
            (nreverse out))))
       (require-keys
        (lambda (bot kind label fields keys)
          (dolist (k keys)
            (let ((v (cdr (assoc k fields))))
              (unless (and v (not (string-empty-p (string-trim v))))
                (user-error "%s: %s %S missing %s" bot kind label k)))))))
  (save-excursion
    (save-restriction
      (widen)
      (org-map-entries
       (lambda ()
         (save-restriction
           (org-narrow-to-subtree)
           (let (name description avatar-shape avatar-color memory groups
                      getting-started visibility)
             (org-babel-map-src-blocks nil
               (let ((field (cdr (assq :json (org-babel-parse-header-arguments header-args))))
                     (text (string-trim (org-unescape-code-in-string (or body "")))))
                 (when (and field
                            (not (string-empty-p text))
                            (not (funcall in-noexport-p)))
                   (pcase (format "%s" field)
                     ("name" (setq name text))
                     ("description" (push text description))
                     ("avatarShape" (setq avatar-shape text))
                     ("avatarColor" (setq avatar-color text))
                     ("gettingStarted" (setq getting-started text))
                     ("visibility" (setq visibility text))
                     ("memory"
                      (let* ((h (funcall heading-at-point))
                             (kind (cond
                                    ((cl-equalp h "profile") "profile")
                                    ((cl-equalp h "log") "log")
                                    (t nil))))
                        (dolist (line (split-string text "\n" t "[ \t]+"))
                          (push (if kind
                                    `((content . ,line) (kind . ,kind))
                                  `((content . ,line)))
                                memory))))
                     ((and section (or "skills" "routines" "plugins"))
                      (let ((place (funcall section-instance-field section)))
                        (unless place
                          (user-error "%s: a :json %s block is not under a field heading"
                                      (or name (funcall heading-at-point))
                                      section))
                        (let* ((instance (car place))
                               (key (cadr place))
                               (id (cons section instance))
                               (cell (assoc id groups)))
                          (unless cell
                            (setq cell (list id))
                            (push cell groups))
                          (funcall push-field cell key text))))))))
             (if (not name)
                 (message "Skipping %s: empty name" (org-get-heading t t t t))
               (when avatar-shape
                 (setq avatar-shape (string-trim avatar-shape))
                 (unless (member avatar-shape avatar-shapes)
                   (user-error "%s: avatarShape %S is not allowed (%s)"
                               name avatar-shape (string-join avatar-shapes " "))))
               (when avatar-color
                 (setq avatar-color (string-trim avatar-color))
                 (unless (member avatar-color avatar-colors)
                   (user-error "%s: avatarColor %S is not allowed (%s)"
                               name avatar-color (string-join avatar-colors " "))))
               (setq description (string-join (nreverse description) "\n\n"))
               (when (string-empty-p (or description ""))
                 (user-error "%s: profile is missing a description" name))
               (when visibility
                 (setq visibility (string-trim visibility))
                 (unless (member visibility '("public" "team"))
                   (user-error "%s: visibility %S is not allowed (public, team)"
                               name visibility)))
               (when getting-started
                 (setq getting-started (string-trim getting-started)))
               (let* ((skill-names nil)
                      (objects
                       (lambda (section required keys)
                         (let (acc)
                           (dolist (g (reverse groups))
                             (when (equal (caar g) section)
                               (let* ((instance (cdar g))
                                      (fields (cdr g)))
                                 (when (equal section "routines")
                                   (let* ((schedule (string-trim (or (cdr (assoc "schedule" fields)) "")))
                                          (content (cdr (assoc "content" fields))))
                                     (setq fields (cl-remove "schedule" fields :test #'equal :key #'car))
                                     (unless (string-empty-p schedule)
                                       (let ((line (format "Schedule: %s (local time)" schedule)))
                                         (when content
                                           (setcdr (assoc "content" fields)
                                                   (concat line "\n" content)))))))
                                 (funcall require-keys
                                          name
                                          (pcase section
                                            ("skills" "skill")
                                            ("routines" "routine")
                                            ("plugins" "plugin"))
                                          (or (cdr (assoc (pcase section
                                                            ("skills" "name")
                                                            ("routines" "slug")
                                                            ("plugins" "pluginId"))
                                                          fields))
                                              instance)
                                          fields
                                          required)
                                 (when (equal section "skills")
                                   (push (string-trim (cdr (assoc "name" fields)))
                                         skill-names))
                                 (push (funcall alist-keep fields keys) acc))))
                           (vconcat (nreverse acc)))))
                      (skills (funcall objects "skills"
                                       '("name" "content")
                                       '("name" "content" "description")))
                      (routines (funcall objects "routines"
                                         '("slug" "description" "content")
                                         '("slug" "description" "content" "name")))
                      (plugins (funcall objects "plugins"
                                        '("pluginId")
                                        '("pluginId" "name" "description")))
                      (file (concat (replace-regexp-in-string
                                     "[^a-z0-9]+" "-" (downcase name))
                                    ".json"))
                      (profile `((name . ,name)
                                 (description . ,description)))
                      (json-encoding-pretty-print t)
                      (coding-system-for-write 'utf-8)
                      obj)
                 (when getting-started
                   (unless (member getting-started skill-names)
                     (user-error "%s: gettingStarted names missing skill %S"
                                 name getting-started)))
                 (when avatar-shape
                   (setq profile (append profile (list (cons 'avatarShape avatar-shape)))))
                 (when avatar-color
                   (setq profile (append profile (list (cons 'avatarColor avatar-color)))))
                 (setq obj `((profile . ,profile)
                             (memory . ,(vconcat (nreverse memory)))
                             (skills . ,skills)
                             (routines . ,routines)
                             (plugins . ,plugins)))
                 (when getting-started
                   (setq obj (append obj (list (cons 'gettingStarted
                                                     (list (cons 'skill getting-started)))))))
                 (when visibility
                   (setq obj (append obj (list (cons 'visibility visibility)))))
                 (when (member file written)
                   (user-error "Two bots tangle to %s" file))
                 (push file written)
                 (with-temp-file (expand-file-name file dir)
                   (insert (json-encode obj) "\n")))))))
       "LEVEL=1-noexport")))
  (message "Wrote %s" (if written (string-join (reverse written) ", ") "no bot files"))
  written)
#+end_src
