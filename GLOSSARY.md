Terms used to describe how work, tools, and toolboxes are organized in my personal workplace.

<a id="benefit"></a>

# benefit

Something good.

<a id="configuration"></a>

# configuration

A [unit](#unit "One cohesive thing.") of [order](#order "A neat, clean, logical, and useful arrangement.") that applies to some object.

<a id="effort"></a>

# effort

The application of energy, knowledge, and skill.

<a id="instruction"></a>

# instruction

A statement that tells a [worker](#worker "A person or AI agent capable of doing work.") what to do.

<a id="order"></a>

# order

A neat, clean, logical, and useful arrangement.

<a id="practice"></a>

# practice

A [process](#process "A configuration of instructions about how to do something.") that [workers](#worker "A person or AI agent capable of doing work.") execute repeatedly or continuously.

<a id="process"></a>

# process

A [configuration](#configuration "A unit of order that applies to some object.") of [instructions](#instruction "A statement that tells a worker what to do.") about how to do something.

<a id="program"></a>

# program

A [process](#process "A configuration of instructions about how to do something.") that a computer can execute.

<a id="settings"></a>

# settings

A [configuration](#configuration "A unit of order that applies to some object.") of values used by a [program](#program "A process that a computer can execute.").

<a id="template"></a>

# template

A useful pattern to copy and fill in.

<a id="tool"></a>


# tool

Something that makes [work](#work "The act of expending effort to bring about some benefit.") easier and/or more productive.

<a id="toolbox"></a>


# toolbox

A directory containing [programs](#program "A process that a computer can execute."), [settings](#settings "A configuration of values used by a program."), [templates](#template "A useful pattern to copy and fill in."), and [practices](#practice "A process that workers execute repeatedly or continuously.") aimed at a specific kind of [work](#work "The act of expending effort to bring about some benefit.").

<a id="unit"></a>

# unit

One cohesive thing.

<a id="work"></a>

# work

The act of expending [effort](#effort "The application of energy, knowledge, and skill.") to bring about some [benefit](#benefit "Something good.").

<a id="worker"></a>

# worker

A person or AI agent capable of doing [work](#work "The act of expending effort to bring about some benefit.").

<a id="workplace"></a>


# workplace

An organization in which [work](#work "The act of expending effort to bring about some benefit.") takes place.
