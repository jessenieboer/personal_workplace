- <<benefit>> :: something good
- <<configuration>> :: a [[unit]] of [[order]] that applies to some object
- <<effort>> :: the application of energy, knowledge, and skill
- <<order>> :: a neat, clean, logical, useful arrangement
- <<practice>> :: a [[process]] that [[worker]]s execute repeatedly or continuously
- <<process>> :: a [[configuration]] of instructions about how to do something
- <<program>> :: a [[process]] that a computer can execute
- <<settings>> :: a [[configuration]] of values for a [[tool]]'s options
- <<template>> :: a useful pattern to copy and fill in
- <<tool>> :: something that makes work easier and/or more productive
- <<toolbox>> :: a collection of practices, programs, settings, and templates aimed at a specific kind of [[work]]
- <<unit>> :: one cohesive thing
- <<work>> :: the act of expending [[effort]] in order to bring about some [[benefit]]
- <<workbench>> :: a personalizable platform for many different kinds of [[work]] (emacs and other editors)
- <<worker>> :: a person or ai capable of doing [[work]]
- <<workplace>> :: an organization in which [[work]] takes place
- <<workspace>> :: a personalizable configuration of software and options on for an operating system (home manager configs)


(defun my/run-project-toolbox-setups ()
  "Load every *_toolbox_setup file under .toolboxes/ in the current project."
  (when-let* ((root (and (project-current)
                         (project-root (project-current))))
              (toolboxes-dir (expand-file-name ".toolboxes" root)))
    (when (file-directory-p toolboxes-dir)
      (dolist (file (directory-files-recursively
                     toolboxes-dir
                     "_toolbox_setup\\'"  ; matches anything ending in _toolbox_setup
                     nil
                     (lambda (dir)         ; optional: skip hidden dirs if you want
                       (not (string-prefix-p "." (file-name-nondirectory dir))))))
        (when (file-regular-p file)
          (message "Loading toolbox setup: %s" file)
          (load file t t t))))))

(add-hook 'envrc-mode-hook #'my/run-project-toolbox-setups)
