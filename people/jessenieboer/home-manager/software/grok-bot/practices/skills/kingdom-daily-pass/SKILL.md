# Kingdom daily pass
Follow capture-item for where the Org files live and how to edit them. For when to hold the whole pass, follow jesse-hardware.

1. List the projects in `_kingdom_management`. Keep only the ones whose CAPTURED_BY_ALL lists you.
2. For each project, read `.toolboxes/project_management_toolbox/_inbox.org` and run the capture-item skill on every entry. Remove an inbox entry only after its capture is verified.
3. Re-read the README's "each day" section (github.com/jessenieboer/personal_workplace, **`jn` branch**, toolboxes/project_management/README; the `master` README is an empty stub) and apply its now/next/past state updates exactly as written. Don't add rules of your own.
4. Report the captures, the state changes, skipped files (and why), overdue repeating items, and any open questions. If none of those happened, say nothing.
