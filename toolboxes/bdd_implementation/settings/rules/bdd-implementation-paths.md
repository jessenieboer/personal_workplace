# BDD implementation paths

- Features (read these; write them with the bdd_spec toolbox): `.toolboxes/bdd_spec_toolbox/features/**/*.feature`
- Definition of Done: `.toolboxes/bdd_implementation_toolbox/definition-of-done.md`
- Plan: `.toolboxes/bdd_implementation_toolbox/PLAN.md`
- Task List: `.toolboxes/bdd_implementation_toolbox/TASK-LIST.md`

Create those paths if they are missing and a skill needs to write.
