** Use :noexport:
#+BEGIN_SRC sh
devenv up -d            # start PostgreSQL 16; creates the database on first start
psql                    # or pgcli; PGDATABASE is the project database
devenv processes down   # stop it
#+END_SRC
*** Details
- initialDatabases :: databases devenv creates on the first start; this toolbox adds postgres_toolbox.database
- PGDATA :: the server data directory, .devenv/state/postgres
- PGDATABASE :: the default database for psql and pgcli; set from postgres_toolbox.database (default culab)
- PGHOST :: the Unix socket directory devenv gives the server
- pgcli :: psql alternative with completion and syntax highlighting
- postgres_toolbox.database :: the database name; set it in the project's devenv.nix
- psql :: the PostgreSQL command-line client
- services.postgres :: the devenv module behind the server; set more options in the project
