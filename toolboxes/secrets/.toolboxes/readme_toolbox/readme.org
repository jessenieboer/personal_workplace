#+html: <p align="center">Tools, settings, templates and practices for managing secrets in projects</p>

* What
Keep project secrets in Bitwarden Secrets Manager and use them in devenv without keeping any secrets in your project repo
** Features :noexport:
* Why
Because in order to use AI in my projects I need to provide api keys, and I don't want to store those insecurely
* For Whom :noexport:
* How
- use Bitwarden Secrets Manager for storing project secrets
- SecretSpec gets secrets from BWS to devenv
- pass stores a token that lets SecretSpec connect to BWS
- pass encrypted with my gpg key
- Yubikey holds my gpg key
** Requirements
- a gpg key
- a local password store initialized with with the gpg key's fingerprint
- a Bitwarden Secrets Manager account
- a BWS project where project secrets live
- a BWS machine account access token
  - created in BWS online portal
  - added manually to pass
  - referenced as a provider in project's secretspec.toml
- provider and profiles setup in ~/.config/secretspec/secretspec.toml
