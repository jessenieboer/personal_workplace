uses
- bitwarden secrets manager to manage secrets
- secretspec to pull secrets out of bws
- pass to hold a bws access token so secretspec can connect to bws without storing that secret in a not-so-secret way
- a script to run devenv commands that can pull private repo stuff out of github

requires
- a bws account
- a bws project where the secrets live
- a bws machine account access token in bws for the machine you're on
  - the access token must be associated with the bws project
- the access token stored locally in pass
- a ~/.config/secretspec/config.toml; generate with secretspec config init or via a home-manager config, looks like:
[defaults]
profile = "dev"
provider = "bws://<project id in bws>"

[defaults.providers]
personal_workplace = "<same as provider above>"
