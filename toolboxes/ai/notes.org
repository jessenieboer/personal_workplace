  notes on agent properties:
  - confirm-tool-calls is nil, t, or auto
  - name defaults to file name
  - description required (use quotation marks)
  - parents are agents that apply before this one
  - model is a symbol (no quotes)
  - backend is a symbol (no quotes) 
  - tools is a list of names of tools in gptel--known-tools (no quotation marks)
  - pre/post are functions such as (lambda () (gptel-mcp-connect '(arxiv) 'sync))
  - the content after the properties drawer is sent as 'system' which is sent as the directive sent at the beginning of each request

    agent org files cannot have any comments or blank values in the properties drawer or gptel won't parse it correctly
