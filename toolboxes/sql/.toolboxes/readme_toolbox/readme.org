** Use :noexport:
*** Details
- .sqlfluff :: sqlfluff configuration (dialect, rules); seeded once
- dialect :: the SQL flavor sqlfluff parses (postgres here)
- migration :: a versioned, ordered change to a database schema
- PGDATA :: the server data directory (.devenv/state/postgres when enabled)
- PGHOST :: where psql connects; devenv points it at the project socket
- psql :: the PostgreSQL command-line client
- sql_toolbox.postgres.enable :: set to true in devenv.nix for a project-local server; start it with devenv up
