# Kingdom daily pass
1. List the projects in `_kingdom_management`. Keep only the ones whose CAPTURED_BY_ALL lists you.
2. For each project, read `_inbox.org` and run the capture-item skill on every entry. Remove an inbox entry only after its capture is verified.
3. Re-read the README's "each day" section and apply its now/next/past state updates exactly as written. Don't add rules of your own.
4. Make every write through the org-safe-edit skill.
5. Report the captures, the state changes, skipped files (and why), overdue repeating items, and any open questions. If none of those happened, say nothing.
