# Grok Bot templates

One JSON file per Grok bot, holding the bot's setup as shown in the Grok Bot app:
name, title, description (the bot's standing instructions), avatar, and per-bot settings.

Exported by Vizier on 2026-10-08. Not included: memories, conversation history, and
routines, which live in Grok Bot rather than in files. Group chats are also left out.

To recreate a bot, make a new bot and paste its name, title, and description from
these files, or ask Vizier to create it from the file.
