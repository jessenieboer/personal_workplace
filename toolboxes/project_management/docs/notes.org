this is about recording (capturing) and organizing (curating) all relevant information for a project so that we can work efficiently on what is most valuable

we use tools (capture templates, curation views) to help do this efficiently

have 2 levels of docs: overview and details

Overview 
- capture everything out of your brain quickly and easily 
- make sure any hard dates are accounted for
- sort items into more/average/less valuable
- check for dependencies of hard-dated and valuable items
- sort items into more/average/less effort required for hard-dated, valuable items that don't have dependencies

* processes:
** capture: record things that need your attention so that you can keep track of everything
  - navigate to project where capture makes sense
  - get out whatever is in your head, perhaps using capture templates as a tool
  - continue what you were doing
** curate: process captured items so that you can prioritize what needs to be done and when
  - use agenda views as tools
  - keep moving things to more value and less effort, compared to other things
*** daily curation (set up work for today or the next)
- clear out inboxes
- activity view: move past items to past and desired items to "now"
*** regular curation (go through a sequence or bounce around between views to determine what to do)
For any given project or group of projects:
1. Hard Dates Check: check to see if any captured items have hard date requirements; fill in date if known. ususally unnecessary as capture templates mark time-bound items as having hard dates
2. Hard Deadlines: fill in dates for items with hard deadlines
3. Tactical Evaluation: per project, for things we can actually work on now, determine what's more/average/less beneficial right now
4. Relevant Dependencies: determine if there are things that need to be done before we can get to the most important stuff: the most valuable stuff, stuff due soon, or stuff we are already doing
5. Effort Estimation: per project, of the important stuff, determine what will take more/average/less effort to finish
6. Soft Scheduling: fill in other dates if desired
7. Activity: set up what we to work on next/now

* tools
** capture templates
Task: work you do 
- Routine: work you do repeatedly
- Practice: work you do continuously
Occurrance: something that happens
- Recurrence: something that happens regularly
Reference: information that needs to be saved for later
Journal entry: freeform writing stored in a date tree

All are "items"
** curation views

*** Occurrence Date Check (`)
- Purpose :: Make sure we know which occurrences will have a date attached so we don't miss any
- Question :: Does this occurrence have a date we need to be aware of?

What's included:
- any occurrence that doesn't have a yes/no value for HAS_DATE
  
Notes:
- this question is usually taken care of by using a capture template

*** Missing Occurrence Dates ([)
- Purpose :: Capture the occurrence dates we still need so that we don't miss any
- Question :: What dates do we still need?

What's included:
- any occurrence that HAS_DATE but doesn't have a TIMESTAMP

*** Occurrance Dates ({)
- Purpose :: Edit occurrence dates
- Question :: Are these dates correct?

What's included:
- any occurrence that has a TIMESTAMP
  
*** Hard Date Check (q)
- Purpose :: Make sure we know which tasks have will have a hard date attached so we don't miss any
- Question :: Does this task have any hard dates we need to be aware of?

What's included:
- any task that doesn't have a yes/no value for HARD_START or HARD_DUE 
  
Notes:
- this question is usually taken care of by using a capture template
  
*** Missing Hard Dates (w)
- Purpose :: Capture the hard dates we still need so that we don't miss any
- Question :: What hard dates do we still need?

What's included:
- anything that has a HARD_START or HARD_DUE but doesn't have SCHEDULED/DEADLINE
  
*** Hard Dates (g)
- Purpose :: Edit hard dates
- Question :: Are these hard dates correct?

What's included:
- any task that has a SCHEDULED or DEADLINE
  
*** Tactical Evaluation (r)
- Purpose :: Figure out what's most beneficial to work on right now so we can focus our efforts on that 

- Question :: How beneficial would this task be if it were finished now?

What's included:
- stuff we can actually work on in the near future (provided any dependencies are taken care of): tasks that don't have a HARD_START or that have a HARD_START within the next 7 days
  
*** Relevant Dependencies (l)
- Purpose :: Note anything that needs to be done before we get to the valuable stuff

- Question :: Are there any tasks that should or must be done prior to these?

What's included:
- anything that is "now" or "next", otherwise
- if item has DEADLINE, must be due within 1 month
- if no deadline, must be tactical value = more

*** Effort Estimation (a)
- Purpose :: Get a rough idea of how much effort relevant items take so we can take that into account when we decide what to work on

- Question :: How much of our effort would it take to finish this now?

What's included:
- independent items that are "now" or "next", otherwise
- if an idependent item has a deadline, must be due within 1 month
- if an independent item has no deadline, must be tactical value = more or average (so we can catch small easy things)

*** Soft Scheduling (r)
- Purpose :: Tentatively set start and finish dates for tasks

- Question :: Do we want to tentatively schedule this?

What's included:
- independent items with no hard dates that are of more value or less effort and avg value

*** Relevant Delegation (SPC)
- Purpose :: Assign items to workers

- Question :: Who is assigned to this?

What's included:
- independent items with no hard dates that are of more value or less effort
  
*** Activity (t)
- Purpose :: Set when we will work on items (now, next, or in the future?)

- Question :: What are we doing?

What's included:
- if independent task has deadline, must be due within 1 week
- if task has no deadline, must be tactical value = more or effort = less and avg value

** reporting views
*** Focus (s)
- Purpose :: Show only what we are working on right now

- Question :: What are we focusing on?

What's included:
- anything "now"

*** Calendar (e)
- Purpose :: See what's coming up

- Question :: "What's on the calendar?"

What's included:
- anything "now"
