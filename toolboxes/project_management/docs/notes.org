* directory structure:
- Kingdom (who has access/control, who reigns, start with capitol)
- _collection (multiple things, prefix with underscore)
- project (organized effort towards a benefit, start with lowercase)
* processes:
** capture: record things that need your attention so that you can keep track of everything
  - navigate to project where capture makes sense
  - get out whatever is in your head, perhaps using capture templates as a tool
  - continue what you were doing
** curate: process captured items so that you can prioritize what needs to be done and when
  - use agenda views as tools
  - keep moving things to more value and less effort, compared to other things
*** daily curation (set up work for today or the next)
- clear out inboxes
- activity view: move desired items to "now"
* practices/disciplines:
- capture everything
- when something out-of current scope comes up, capture and continue
- manage on computer, go-mode on phone
* documentation
- definitions of capture templates
  - tasks: things you do
  - occurrences: things that happen
- how to use views
- process of working through the views
  
* org repeating tasks:

+1w - repeats on this day every week
+1w -3d - repeats with warning period
++1w - marking as done makes sure the next date is in the future
.+1w - marking as done shifts the date to 1 week after today
* tools
** capture templates
Task: work you do once
Routine: work you do repeatedly
Practice: work you do continuously
Occurrance: something that happens
Recurrence: something that happens regularly
Reference: information that needs to be saved for later
Journal entry: freeform writing stored in a date tree
** views
*** all dependencies
"Are there dependencies for these tasks?"
- everything

*** relevant dependencies
"Are there dependencies for these tasks?"
- anything that is "now" or "next", otherwise
- if item has deadline, must be due within 2 weeks
- if no deadline, must be tactical value = more
  
*** tactical evaluation view
"How beneficial would this task be if it were finished now?"
- non-repeating tasks

"How beneficial would this routine be if it were finished now?"
- repeating tasks

*** activity view
"When are we doing these things?"
- not dependent on anything
- if item has deadline, must be due within 1 week
- if no deadline, must be tactical value = more or effort = less
