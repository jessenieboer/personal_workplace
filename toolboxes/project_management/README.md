<h1 align="center">Project Management Toolbox</h1>


# What

Tools, settings, and instructions for how I manage projects. This replaces the
Org-based [org_project_management](../org_project_management) toolbox, which is
being phased out.


# Use

In a project's `devenv.yaml`:

    imports:
      - personal_workplace/toolboxes/project_management
