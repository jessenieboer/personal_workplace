- node_modules :: installed dependencies; rebuilt from package-lock.json
- npm :: the Node.js package manager and script runner
- package.json :: project metadata, dependencies and scripts
- package-lock.json :: the exact dependency tree npm installed; commit it
- script :: a named command in package.json, run with npm run <name>
